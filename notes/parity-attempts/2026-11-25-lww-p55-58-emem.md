## Derivations (labels: Literature = read in source with page; Proved here; Computed = script below)

**D1. Set-up of E_mem (p. 55).** Literature: c_γ is the term of the untruncated distinct expansion. E_mem =
prod b'_p Σ_γ |c_γ| 1[max_{0<=t<=4R+1} Σ_i k_i^{(t)} > ⌈L^2⌉].
- Proved here: the restricted operators of p. 49 restrict *every* intermediate state, since each kernel carries both
  1[|m| <= ⌈L^2⌉] and 1[|m'| <= ⌈L^2⌉], and the 4R+2 states are t = 0..4R+1. So the truncated expansion is exactly
  {γ : max_t Σ k^{(t)} <= ⌈L^2⌉}.
- Hence M_R = prod b'_p (truncated) + prod b'_p (rest), with |prod b'_p (rest)| <= E_mem.
- Each O_j appends at most K pairs (|S| <= K), and m is empty at t = 0 (b). So a counted γ has
  #(G-appended) >= ⌈L^2⌉ + 1 - 2KR, and 1 <= 2^{#G - (⌈L^2⌉+1-2KR)}.
- Printed: 2^{-⌈L^2⌉+2KR}. This is weaker by a factor 2 and valid (S1).

**D2. Non-tuple prime factor (p. 55).** Proved here + Computed (C).
- Under distinctness, a prime p in no tuple is either never selected, or appended at G_a and removed at G_c.
- Removal acts only on pre-existing coordinates (p. 48), so c > a.
- b forces m to be empty at the end, so the pair is always removed.
- Being moved into a tuple would make A_p nonempty.
- With absolute values, the ϑ-factors pair off exactly as in (4.122). This holds for positive quantities too:
  - append: (η'_aV_iν_i/ϑ)·ϑ;
  - matched retained: ϑ·(q_j/ϑ^2)·ϑ = q_j;
  - unmatched: 1;
  - remove: ϑ·(η'_c/ϑ).
- So the factor is 1 + (2/((p+1)b'_p)) Σ_{a<c} η'_aη'_c 1[...] prod_{a<j<c}(1 - η'_j 1[...]), exactly as printed,
  with V_iν_i = 1/((p+1)b'_p) by (4.120).
- Telescoping: for y_j ∈ [0,1], Σ_{c>a} y_c prod_{a<j<c}(1-y_j) = 1 - prod_{a<j<=2R}(1-y_j) ∈ [0,1].
  η'_j ∈ (0,1) because q_j ∈ (0,1). So the factor is <= 1 + 2·2R/((p+1)b'_p) <= 1 + 2(2R+1)/((p+1)b'_p) as printed.
- This is << R/p, since b'_p = 1 - O(R/p) >= 1/2 for p >= e^{L^{0.1}}.
- Product: prod(1 + C_ρR/p) <= exp(C_ρR Σ_{∪P_i} 1/p) = exp(C_ρR Σ_i V_i) <= exp(C_{K,ρ}R), using V_i < 1.
- Computed (C): a literal DP over the G_j/O_j rules (removal before append, ϑ^{h_s+h_t}, empty m at the end, factor 2
  per G-append) reproduces the printed sum exactly. 311 random exact cases (p <= 13, R <= 4, random ϑ, V, √ρ, lines),
  0 failures.
  - NEG: dropping h_t breaks it (225/311 mismatches).
  - NEG: η' = 3/2 gives a telescoped sum 9/8 > 1, so the bound uses η' <= 1.
