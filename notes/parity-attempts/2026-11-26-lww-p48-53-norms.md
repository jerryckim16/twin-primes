**N1. Weighted Schur test (4.123), p. 49.**
- Proved here. Cauchy-Schwarz with weight w gives ||T||_{L^2(m)} <= sqrt(R C), where
  - R = sup_s w(s)^{-1} Σ_t |a| w(t) m(t);
  - C = sup_t w(t)^{-1} Σ_s |a| w(s) m(s) = R(T*) (the T* kernel is conj a(t,s) w.r.t. m).
- Computed (B): 400 random complex cases, 0 failures; C = R(T*) in all cases.
- Detection controls: "||T|| <= R" fails 39/400; C taken with m(t) for m(s) fails 5/400.

**N2. G_j row/column factors, p. 49.**
- Proved here. Row of G_j: for each of the h_i matching coordinates, removal gives (η'_j/ϑ)v_0^{-1} and retention gives
  q_j/ϑ^2. Appends give Σ_l (v_0η'_jV_is_i/ϑ)^l/l!. This is exactly the printed factor.
- Column, via the factorial identities (Computed (A): 961 cases exact; control "drop a!" fails 899/961):
  - each matching coordinate of t was retained (q_j/ϑ^2) or appended (η'_jV_i/(ϑv_0), the ν cancels with the measure);
  - removed coordinates give exp(v_0η'_js_i/ϑ).
- Both parentheses are <= √ρ/ϑ^2 + 1/(ϑv_0) < 1: the maximum over q_j ∈ {√ρ, ρ} is at q = √ρ, and V_i < 1.
- Computed (C): brute force on multisets (symmetric functions), one group, exact rationals. Row and column sums equal the
  truncated printed factors in 228/228 cases. Same for O_j's ϑ-products: ||G_j|| ≪_{K,ρ} 1. ✓
- **S2 (terse).** The bound holds for operators on *symmetric* functions, i.e. the kernel averaged over orderings. The
  literal "append at the end" kernel on ordered tuples, with measure Πλ/k!, has column sums with a factor k'.
  - Computed (C), illustration: for k' = 6 it exceeds the printed factor in 12/12 parameter sets.
  - LWW states the invariance (p. 47, "The functions are invariant under permutations"), so this is implicit, not
    wrong.
