## Findings

### Errors in the card
- **E1 (S3 misquote; p. 43-45).** The card says "(q_1⋯q_B, S_0) = 1 ... is in E_B's definition (p. 43)". That is
  false.
  - The coprimality appears only in the full expansion line of F(ℓ(P)) on p. 43, and as "p ∤ S_0" in (4.115).
  - It is **absent** from the display defining F_{<B} and E_k (p. 43, the line just before (4.112)). It is also
    absent from (4.113), from the F_{<B} display on p. 44, and from the definition of F_{<B}(ℓ) on p. 45
    (checked at 240 dpi).
  - The card's harmlessness argument ("H >= 0, so the dropped constraint only enlarges an upper bound") covers only
    E_B and (4.113)-(4.115). It does not cover F_{<B}. Read literally, F_{<B} would include q | S_0, and then
    (4.112) is false and the main term changes.
  - **Fix:** restate S3 as follows. "From the F_{<B} display on p. 43 onward, the condition (q_1⋯q_k, S_0) = 1 is
    implicit in every q-sum (E_k, (4.113), p. 44, p. 45). It must be read that way for (4.112). With that reading
    everything closes." It stays a cosmetic or notational slip, but the card should say where it occurs and why it
    is needed.
- **E2 (N5, #R paragraph).** The card says "Its coefficient vanishes only if det(z,w) = 0, so it has <= 1 root".
  This is false as stated.
  - The coefficient 2(n±ϑ)z_2 − 2aw_2 can vanish with det(z,w) = 1. In that case there is simply no root.
  - The correct statement: the coefficient and the constant term vanish together only if (n±ϑ)z = aw, i.e.
    det(z,w) = 0. Hence there is at most one root.
  - LWW's own argument is cleaner and correct: ∂_r[aτ(w)/τ(z)] = −2a/τ(z)^2 ≠ 0, so the function is strictly
    monotone on the interval where τ(z) > 0.
  - The script's (F) already handles this correctly (lines 375-378).
  - **Fix:** reword along these lines.
