## Point-by-point (the six questions asked)

### (1) Hypotheses of Thm 3.1 for g1 = g2 = λ

- 1-bounded multiplicative: yes (completely multiplicative, values ±1).
- Case (ii) needs δ_N = 0 for all X^{0.4} ≤ N ≤ X (a choice, permitted) and (3.3), exp(M(g1; X², log^{1/125} X)) ≫ L. With
  L = (log X)^{1/4}: TT's M(g; Y, Q) (1.18) is the infimum over |t| ≤ Y, q ≤ Q, χ mod q of Σ_{p≤Y}(1 − Re λ(p)χ̄(p)p^{−it})/p =
  Σ_{p≤Y}(1 + Re χ̄(p)p^{−it})/p. The infimum is symmetric under (χ, t) → (χ̄, −t). Dropping the primes p < exp((log Y)^{2/3+ε})
  (non-negative terms) and applying the *last* inequality of MRT (1.12) at Y = X², with q ≤ log^{1/125} X ≤ log^{1/125}(X²),
  ε = 1/12, gives M ≥ (1/4) log log X − O(1). So exp(M) ≫ (log X)^{1/4}. ✓ Also 1 ≤ L ≤ log X for X ≥ e. ✓
- L^c = (log X)^{c/4} = (log X)^κ with κ = c/4: the modulus range W ≤ (log X)^κ, the saving (log X)^{−κ}, and
  ∫_E dt/t ≪ (log X)^{1−κ} are all correctly transcribed. ✓
- N real: TT's §3.2 reduces to an integral ∫_{√X}^X … dN/N by Markov, so N ∈ [√X, X] \ E is a real parameter. This is what
  Step 1 needs. ✓
- h1 = 0, h2 = 2 ≤ L^c once X is large; b ∈ [0, W) settles the ambiguity of "b = O(L^c)". ✓

### (2) Uniformity in W, b, h1, h2 and E

The theorem reads "there exists a set E … such that for any W ∈ [L^c] and integers b, h1, h2 … we have (3.4) for all
N ∈ [√X, X] \ E". E is quantified before W, b, h, so one E(X) serves all of them (for the fixed pair g1, g2 and the fixed X). The
union-bound sentence of §3.2 confirms it. ✓ E does depend on X, and the note uses a separate E(X_j) at each scale, which is
correct. Non-coprime classes (c = 0, c = e − 2, …) are covered, because b is an arbitrary integer. ✓

### (3) Dyadic to logarithmic, and the exceptional scales

- Σ_{n≤x} f(n)/n = ∫_0^x F(N) N^{−2} dN, with F(N) = Σ_{N<n≤min(2N,x)} f(n), is exact. ✓
- The ranges (A) (x/2, x], (B_0) [√x, x/2], (B_j) [X_{j+1}, X_j] (1 ≤ j ≤ J) and (C) (0, X_{J+1}) tile (0, x]. ✓ On every (B_j),
  2N ≤ x, so F is an untruncated dyadic sum, and E(X_j) ⊂ [X_{j+1}, X_j] is exactly the range on which (T) at X = X_j is used. ✓
- The requirement e ≤ (log X_j)^κ for all j ≤ J follows from e ≤ (log x)^{κ/2}, because log X_j ≥ (log x)^{1/2}. ✓ X_J ≥ X_* for
  large x. ✓
- Non-exceptional part: C_1(log X_j)^{−κ}·(1/e)·(1/2)log X_j ≤ C_1(log x)^{−κ/2}(log X_j)/(2e), and Σ_j log X_j ≤ 2 log x. ✓
  (This is lossy. The sum is in fact geometric, ≍ (log x)^{1−κ}/e, but the loss is harmless.)
- Exceptional part: (1/e)·O((log X_j)^{1−κ}) + 1/X_{j+1}, summable. ✓ Low range (C): ≤ 1 + (2 + (log x)^{1/2})/e. ✓
- Lemma A, |S(e,c;x)| ≤ C_2(log x)^{1−κ/2}/e + 2: ✓ (the constant collects 1 from (C), plus O(1/e) and o(1)).

### (4) Residue classes and the summation over (d1, d2, c)

- The expansion w_R(n) = Σ_{d1,d2≤R} λ_{d1}λ_{d2} Σ_{c∈C_e} 1_{n≡c (e)} with e = [d1,d2] is exact. ✓
- ρ(p^k) = 2 for odd p; ρ(2) = 1, ρ(4) = 2, ρ(2^k) = 4 for k ≥ 3; ρ(e) ≤ 2^{ω(e)+1}; #{[d1,d2] = e} = τ(e²). All verified,
  by hand and numerically. ✓
- e ≤ R² is needed (each class is fed to (T) with W = e). The note imposes R² ≤ (log x)^{κ/2}, that is R ≤ (log x)^{κ/4}, and then
  c0 = κ/4. ✓ (The question "must e ≤ L^c?" is answered yes, and it is satisfied, with room to spare, at the smallest scale X_J.)
- Σ_{e≤R²} ρ(e)τ(e²)/e ≤ ∏_{p≤R²}(…) ≪ (log R)^6. ✓ Σ_{d1,d2≤R} ρ([d1,d2]) ≤ 2R²·max_{e≤R²} 2^{ω(e)} ≪_ε R^{2+ε}, uniformly. ✓
- Error ≪ (log R + 1)^6 (log x)^{1−κ/2} + R^{2+o(1)}. ✓

### (5) The main-term lower bound for arbitrary λ_d. The suspicion is unfounded.

The bound does **not** use any optimality of the λ_d. For odd n with p ∤ n(n+2) for every prime 3 ≤ p ≤ R, every d ≤ R with
d | n(n+2) has all its prime factors ≤ R and dividing n(n+2). So d = 1, and Σ_{d|n(n+2), d≤R} λ_d = λ_1 = 1 *identically*, whatever
the other λ_d are. Cancellation among the λ_d cannot occur on S_R, because only one term is present there. With w_R ≥ 0 this gives
Σ_{n≤x} w_R(n)/n ≥ Σ_{n≤x} 1_{S_R}(n)/n ≥ δ_R log(x/P) − 1. The partial summation is correct: A(t) ≥ ⌊t/P⌋δ_R P ≥ δ_R t − P.
It holds even without |λ_d| ≤ 1. This is the Selberg phenomenon: the minimum of the mean over λ with λ_1 = 1 is ≍ (log R)^{−2},
and S_R exhibits the lower bound directly. Numerically, the exact unconstrained minimum of the mean stays above δ_R (see header).
Because the error in Step 3 is bounded with |λ_{d1}λ_{d2}| ≤ 1 term by term, and not through cancellation, the "relative error"
concern does not arise: the error bound is absolute, and the main term is never smaller than δ_R log x·(1 − o(1)). ✓

The only degenerate case is λ_1 = 0, which the hypotheses exclude. By homogeneity of degree 2, the result extends verbatim to
λ_1 ≠ 0 and |λ_d| ≤ |λ_1|.

### (6) Hidden dependence of constants

- c_TT is fixed once ("sufficiently small absolute constant"), so implied constants in (3.4) and in the density of E may depend
  on c_TT and on the implied constant of (3.3). Both are fixed absolutely here, via MRT's O(1) at ε = 1/12, which is absolute and
  effective per MRT. ✓ TT's notation (§1.6) says only "for some constant C". Reading this as uniform in X, g1, g2 (subject to the
  hypotheses) is the only meaningful reading of a theorem stated "Let X ≥ 2 …". TT's own Remarks 3.2 (third bullet) and §4 use it
  that way. The note flags this as a reading, which is appropriate.
- Uniformity in R and λ: the (log R)^6, R^{2+ε} and δ_R bounds are uniform with absolute constants. ✓ x_0 is absolute, not
  effective (TT silent). ✓
