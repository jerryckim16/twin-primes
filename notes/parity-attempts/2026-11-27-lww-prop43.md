**D0. Objects (pp. 19, 23-24).** Proved here.
- S is finite: Ω is bounded and each P_i is finite. So H is finite-dimensional (T5).
- σ ≡ σ_0 := ∏V_i^{-(J+1)} is constant. With the inner product (4.21), the adjoint is the conjugate transpose of the
  kernel matrix.
- A := A_{-2}^C = G_{-2} S T_{-2}^C S G_{-2}. G_{-2} is a diagonal 0/1 multiplier. S averages over the permutations of
  p at **fixed** P (4.32), so it acts within the fibre {(P, ·)}. T_{-2}^C(·)(P, p) is a sum over states (Q, p') with
  Q ∈ C, weighted by ψ_{-2}(det(P,Q)/(DY))·1_{d_0≤D<2d_0}·(...).
- B := AA*. It satisfies ⟨h, Bh⟩ = ‖A*h‖² ≥ 0, so B is Hermitian PSD, and so is B^R. ✓

**D1. f and g (pp. 24-25, 28).** Proved here.
- f is C-supported (T1). Positions of S are primitive by (4.19). If f(P) ≠ 0, then β_{P_2} ≠ 0, so R_Z(P_2) = 1, so
  P_2 is odd (P_2 ≥ N > 1 and Z > 2). Also α_{P_1/G(P_1)} ≠ 0, so P_1/G(P_1) has no prime factor ≤ Z; and G(P_1) is a
  product of primes in ∪P_i ⊂ (2, Z) ((2.12): exp(2L^{0.2}) < exp(L^{0.24}); the P_i are pairwise disjoint, p. 7).
  So P_1 is odd and P ∈ C. ✓
- f(P, p) = f(P) is constant on fibres (by definition (4.42)). This is what makes f_j = Σ_{P∈Ω∩C, P_2/P_1∈I_j}
  f(P)u_P exact (p. 29). ✓
- sup|f| ≤ L^{2C}, from the Prop. 4.2 hypotheses. ✓
- (4.43), re-derived. Fix the tuples and put m_0 = ∏_{i,j≤J+1} p_{i,j}. The K(J+1) primes are distinct: within a
  tuple by (4.19), and across tuples because the P_i are pairwise disjoint (p. 7, (2.12)). So m_0 | P_1, and the number of such P_1 in
  [d_0YM, 16d_0YM] is ≤ ⌊16d_0YM/m_0⌋. So #{P} ≤ (N+1)·16d_0YM/m_0 ≤ 32d_0YMN/m_0. Dropping distinctness and using
  V_i = Σ_{p∈P_i} 1/p (p. 7) gives Σ_{(P,p)∈S} σ ≤ 32 d_0YMN. Hence ‖f‖² ≤ 32 d_0YMN L^{4C}. ✓
- g = f satisfies (4.56). ✓
